## Import Notes

- These are horizontal strips (4 frames typical).
- Transparent background, thin black outline, flat colors.
- Import via GB Studio Sprites panel.
- For the first playable level, start with one player sheet + the red blob enemy + star collectible.
- Use left/right versions for directional walking once the core loop is working.

Generated for the GrokBotPlatformer project.
